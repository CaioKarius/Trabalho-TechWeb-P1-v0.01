# 📁 Portfólio Pessoal - Front-End 

Este é meu projeto final desenvolvido durante o curso **Tecnologia Web - Engenharia da Computação (Front-End)**. Trata-se de um site de portfólio pessoal totalmente lúdico envolvendo o universo geek

---

## 📌 Sobre o Projeto

Este site foi criado com foco em aplicar os conhecimentos de **HTML**, **CSS**, **Flexbox**, **responsividade** e **publicação com GitHub Pages**.

O projeto foi dividido em duas fases:
- **Parte 1 (Semana 5):** Estruturação HTML e protótipo no Canva  
- **Parte 2 (Semana 6):** Criação e amadurecimento do conceito e criação dos textos
- **Parte 3 (Semana 7):** Criação de imagens via IA Generativa
- **Parte 4 (Semana 9):** Acertos da estilização
- **Parte 5 (Semana 11):** Finalização com responsividade, interatividade e publicação online


---

## 🧪 Funcionalidades

- Página **Santos de Ouro** com imagens, história, pequeno diálogo e poderes dos personagens
- Seção de **Especificas** para fácil localização de cada personagem
- **Layout responsivo** (mobile e desktop)

---

## 🧰 Tecnologias Utilizadas

- HTML5
- CSS3 + Flexbox
- Google Fonts
- Font Awesome
- Git + GitHub
- GitHub Pages (para publicação)
- Gemini
